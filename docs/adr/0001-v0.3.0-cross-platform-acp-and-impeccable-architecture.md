# ADR 0001: Cross-Platform Runtime Parity, Real ACP/Pi Mesh Handshakes, and Impeccable Operate Design System

- **Status**: Accepted
- **Date**: 2026-10-24

## Context

A full-system audit of Antigravity Swiss Knife identified four structural gaps:
1. **Backend Security & State Integrity**: Version drift (`0.1.0` in Go vs `0.2.0` in `package.json`), standalone CLI mock quota output, unshielded active cascades during concurrent cache pruning, missing SSRF validation in the custom-model gateway, raw PIN values stored in remote auth cookies, and `0644` permissions on bridge credential files.
2. **ACP Server & Pi Agent Mesh**: `antigravity-acp` rejected newer client protocol versions, advertised `loadSession` and `session/list` unconditionally on surfaces that did not implement them, dropped top-level `conversation_id` on CLI resume, and seeded LS step offsets after sending prompts. Meanwhile, `pkg/acpmesh` only checked raw TCP/socket openness without speaking ACP JSON-RPC or Pi RPC (`pi --mode rpc` / `pi-acp`).
3. **Cross-Platform Parity & CI**: macOS process discovery relied on Linux `/proc`, Windows `.cmd` scripts were passed directly to `CreateProcess`, several account and importer paths hardcoded `~/.config/Antigravity`, Electron `main.js` hardcoded `~/.config/antigravity-swiss`, and GitHub Actions lacked macOS and `antigravity-acp` test jobs.
4. **UI Design System**: The frontend lacked `PRODUCT.md`, `DESIGN.md`, and `.impeccable/design.json`, imported `Roboto`, referenced 11 undefined CSS custom properties, and used hardcoded `#ffffff` surfaces that reduced dark-mode contrast below WCAG AA.

## Decisions

1. **Unified Version & Honest Telemetry**:
   - Set `core.AppVersion = "0.2.0"` and report `runtime.Version()` from `swiss version`.
   - Remove standalone fabricated quota output from `cmd/swiss`; when the daemon is unreachable, return cached quota with a warning or fail with exit code 1.
   - Enforce `.prune.lock` in `pkg/cache/pruner.go` and merge active cascade IDs discovered from `conversation_summaries.db` after acquiring the lock.

2. **Gateway SSRF Guard & Bridge Hardening**:
   - Validate all upstream custom-model gateway requests with `ValidateEndpointSSRF` prior to dispatch.
   - Persist bridge configuration files atomically with `0600` permissions, synchronize `AuthManager` credentials immediately on update, and issue HMAC-signed session cookies for Remote Control login instead of storing raw PINs in cookies.

3. **ACP Protocol Completeness & Live Pi RPC Integration**:
   - Negotiate protocol version in `antigravity-acp` by returning the supported server version, derive capabilities from implemented surface interfaces (`HistoryProvider`, `SessionLister`, `ModelSelector`), format Windows/UNC/POSIX workspace URIs via `url.URL`, and guard session state against concurrent prompts.
   - Implement `ProbeAgentHandshake` and `PromptAgent` in `pkg/acpmesh/handshake.go` to execute real JSON-RPC 2.0 `initialize` / `session/prompt` handshakes against stdio ACP servers (`antigravity-acp`, `pi-acp`) and `get_state` / `prompt` RPC calls against `pi --mode rpc`.

4. **Cross-Platform Process, Path, and CI Parity**:
   - Fall back to `ps` process table enumeration on macOS where `/proc` is absent.
   - Resolve native `.exe` binaries or escape `cmd.exe` metacharacters when invoking `.cmd`/`.bat` launchers on Windows.
   - Route all host and companion config paths through `core.GetAntigravityHostConfigDir()` and `core.GetConfigDir()` (and matching `getSwissConfigDir()` in `electron/main.js`).
   - Run Go, `antigravity-acp`, Electron, and Frontend test suites across `ubuntu-latest`, `windows-latest`, and `macos-latest` in GitHub Actions, and bundle `antigravity-acp` in release artifacts.

5. **Impeccable `Operate` Mode Design System**:
   - Codify the `"Precision Instrument Deck"` visual system in `PRODUCT.md`, `DESIGN.md`, and `.impeccable/design.json`.
   - Define all semantic light and dark tokens in `frontend/src/index.css`, remove `Roboto` `@import` and dead `App.css`, and replace hardcoded light card backgrounds with `var(--surface)`.
