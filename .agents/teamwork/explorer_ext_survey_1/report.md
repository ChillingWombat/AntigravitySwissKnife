## Executive Summary

This report surveys the frontend, companion daemon, and persistent preload script architecture of **Antigravity Swiss Knife** to establish the foundation for implementing:
- **R1**: Auxiliary Panel Tab Injector Engine (`persistent_script.js`, `pkg/gui/styler.go`, `pkg/plugins/auxiliary.go`)
- **R2**: Live Browser Preview & Visual Canvas Annotation Tool (embedded `<webview>`, red pen, bounding box, DOM selector, Lexical & file input chat integration, mobile frames)
- **R6**: Real In-Chat Token & TPS Telemetry Badge (`transcript.jsonl`, Google Material badge, subagent token aggregation)
- **R7**: Quick Memos with Real Audio Recording (MediaRecorder API WebM/Opus, waveform scrubbing, drag-and-drop to composer)

The survey verified that while initial proof-of-concept skeletons exist in `pkg/plugins/auxiliary.go` and `frontend/src/pages/FeaturePluginsPage.tsx`, significant discrepancies and missing capabilities must be bridged to achieve production readiness and satisfy all acceptance criteria.

  - `GenerateScriptWithCustomModels(cfg, cmCfg)` (lines 978–1009): Appends `plugins.GenerateAuxiliaryPluginsScript()`, but redundantly re-appends `customScript` if already generated by `GenerateScript`.

#### 1.2 Identified Architectural Gaps for R1
1. **Navbar Selector Mismatch**:
   - *Requirement*: Inject into Antigravity 2.0 right auxiliary navbar: `.shrink-0.flex.items-center.gap-0.5.border-b`.

2. **Button Attribute Specification**:
   - *Requirement*: Inject native `<button>` elements with `data-tab-id="swiss-browser"`, `data-tab-id="swiss-files"`, `data-tab-id="swiss-memos"`.

3. **Mounting Container Location**:
   - *Requirement*: Mount `#swiss-aux-container` inside the body container `.flex-grow.overflow-hidden`.
   - *Current Code* (`pkg/plugins/auxiliary.go:427`): Appends `#swiss-aux-container` directly to the top-level `auxPanel`, violating layout isolation and flex tree hierarchy.

5. **Script Generator Integration (R8 link)**:
   - `GenerateScript(cfg)` in `pkg/gui/styler.go` must be updated to bundle `plugins.GenerateAuxiliaryPluginsScript()`.

### R6. Real In-Chat Token & TPS Telemetry Badge

#### 4.1 Current Architecture & Code Locations
- **`pkg/plugins/auxiliary.go`**:
  - `setupInChatTelemetry()` (lines 1070–1098): Queries assistant steps (`[data-testid="assistant-step"]`, etc.) and injects `.swiss-telemetry-badge`.
- **`pkg/webgui/server.go`**:

- **Antigravity Brain Logs & Databases**:
  - Primary Log: `~/.gemini/antigravity/brain/<conversation_id>/.system_generated/logs/transcript.jsonl`.
  - SQLite Conversation Summaries: `~/.gemini/antigravity/conversation_summaries.db` (contains `conversation_id`, `parent_conversation_id`, `step_count`).
  - SQLite Trajectory Databases: `~/.gemini/antigravity/conversations/<conversation_id>.db` (contains `steps`, `gen_metadata`, `trajectory_meta`).

#### 4.2 Identified Architectural Gaps for R6
1. **Synthetic vs. Real Telemetry**:
   - *Requirement*: Parse exact token metrics (prompt, cached, output), duration, and generation speed from Antigravity session transcript logs (`transcript.jsonl`).
   - *Current Code* (`pkg/plugins/auxiliary.go:1078–1083`): Uses a hardcoded synthetic formula:
     ```javascript
     const outToks = Math.max(32, Math.round(turnText.length / 3.8));
     const inToks = Math.round(outToks * 1.8) + 350;
     const cachedToks = Math.round(inToks * 0.45);
     const tps = (62 + (idx * 3.5) % 24).toFixed(1);
     ```
     This does **not** query real session data.
2. **Subagent Aggregation**:
   - *Requirement*: Aggregate subagent token consumption across spawned child subagents.
   - *Current Code*: Hardcodes `${idx % 2 === 0 ? '<span class="metric-subagent">1 subagent</span>' : ''}`.
3. **Backend Parsing Support**:
   - `pkg/webgui/server.go` estimates tokens using file size `info.Size() / 4`. It needs a dedicated parser to read real JSONL lines from `transcript.jsonl` (and child subagent `transcript.jsonl` files identified via `conversation_summaries.db`) and expose turn-level metrics.

## 2. Technical Architecture & Interface Contracts

### 2.1 R1 Contract & DOM Mechanics

```
Antigravity Auxiliary Panel (.part.auxiliarybar or [data-testid="auxiliary-panel"])
├── Navbar Header: .shrink-0.flex.items-center.gap-0.5.border-b
│   ├── Factory Tabs:
│   │   ├── <button data-tab-id="overview">Overview</button>
│   │   ├── <button data-tab-id="review">Review</button>
│   │   └── <button data-tab-id="terminal">Terminal</button>
│   └── Injected Swiss Button Group (.swiss-aux-btn-group):
│       ├── <button class="swiss-aux-tab-btn" data-tab-id="swiss-browser">🌐 Browser</button>
│       ├── <button class="swiss-aux-tab-btn" data-tab-id="swiss-files">📁 Files</button>
│       └── <button class="swiss-aux-tab-btn" data-tab-id="swiss-memos">📝 Memos</button>
└── Content Viewport: .flex-grow.overflow-hidden
    ├── Factory Views (display: none when Swiss tab active)
    └── Injected Container: #swiss-aux-container (display: flex when Swiss tab active)
        ├── .swiss-browser-view (active when data-tab-id="swiss-browser")
        ├── .swiss-files-view   (active when data-tab-id="swiss-files")
        └── .swiss-memos-view   (active when data-tab-id="swiss-memos")
```

#### State Synchronization Flow
1. **User clicks Swiss Tab** (`swiss-browser`, `swiss-files`, `swiss-memos`):
   - Add `.active` class to clicked button; remove from other Swiss and factory buttons.
   - Locate `.flex-grow.overflow-hidden`. Iterate over direct children; for any child that is not `#swiss-aux-container`, set `display: none !important`.
   - Ensure `#swiss-aux-container` is present inside `.flex-grow.overflow-hidden`. Set `display: flex !important`.
   - Mount/render the selected view (`renderBrowserView`, `renderFilesView`, or `renderMemosView`).
   - Store state in `window.localStorage.setItem('antigravity_active_aux_tab', tabId)`.
2. **User clicks Factory Tab** (`overview`, `review`, `terminal`):
   - Listen to click events on `tabHeader`. If target does not match `[data-tab-id^="swiss-"]`:
   - Set `#swiss-aux-container.style.display = 'none'`.
   - Restore factory children: iterate over direct children of `.flex-grow.overflow-hidden` and reset `display = ''`.
   - Remove `.active` class from all `[data-tab-id^="swiss-"]` buttons.
   - Store state in `window.localStorage.setItem('antigravity_active_aux_tab', 'factory')`.
3. **Tab Restoration**:
   - On `DOMContentLoaded` or after DOM reconstruction, read `localStorage.getItem('antigravity_active_aux_tab')`. If it starts with `swiss-`, invoke `switchAuxTab(savedTab)`.

#### DOM Element Selector Algorithm
Execute script within webview or iframe:
```javascript
function enableDOMInspector(webview, onSelect) {
  const inspectCode = `
    (() => {
      let hovered = null;
      const overlay = document.createElement('div');
      overlay.style.position = 'fixed';
      overlay.style.pointerEvents = 'none';
      overlay.style.border = '2px solid #ea4335';
      overlay.style.backgroundColor = 'rgba(234, 67, 53, 0.15)';
      overlay.style.zIndex = '999999';
      document.body.appendChild(overlay);

      function updateBox(e) {
        hovered = e.target;
        const r = hovered.getBoundingClientRect();
        overlay.style.top = r.top + 'px';
        overlay.style.left = r.left + 'px';
        overlay.style.width = r.width + 'px';
        overlay.style.height = r.height + 'px';
      }

      function clickHandler(e) {
        e.preventDefault();
        e.stopPropagation();
        overlay.remove();
        document.removeEventListener('mousemove', updateBox);
        document.removeEventListener('click', clickHandler, true);
        const sel = getCssSelector(hovered);
        const html = hovered.outerHTML.slice(0, 1000);
        return { selector: sel, html: html };
      }

      document.addEventListener('mousemove', updateBox);
      document.addEventListener('click', clickHandler, { capture: true, once: true });
    })()
  `;
  // Execute via webview.executeJavaScript or postMessage
}
```

### 2.4 R7 Contract: Quick Memos & Audio Recording

#### Data Structure (`~/.config/antigravity-swiss/memos.json`)
```json
[
  {
    "id": "memo-audio-1728169999",
    "title": "Voice Memo (0:14)",
    "content": "Check database migrations before deployment",
    "type": "audio",
    "audio_data": "data:audio/webm;codecs=opus;base64,GkXfo59ChoEBQveBAULygQ8...",
    "duration": "0:14",
    "peaks": [12, 25, 48, 85, 92, 60, 45, 30, 75, 88, 54, 20],
    "created_at": "2026-10-05 22:20",
    "tags": ["voice", "quick"]
  }
]
```

#### Waveform Scrubbing & Drag-and-Drop
- **Recording**: MediaRecorder records `audio/webm;codecs=opus`. On stop, `FileReader.readAsDataURL` encodes the complete audio to base64 `audio_data`.
- **Waveform Canvas**: Renders 32–48 vertical rounded bars on `<canvas class="swiss-memo-waveform">`.
  - Blue (`#1a73e8`) for progress $\le \text{currentTime} / \text{duration}$.
  - Gray (`#cbd5e1`) for unplayed segment.
  - Clicking on the canvas scrubs `audio.currentTime = (event.offsetX / canvas.width) * audio.duration`.
- **Drag-and-Drop**:
  - `card.ondragstart`:
    - For audio: Converts `audio_data` back to Blob $\to$ `new File([blob], 'memo-voice.webm', { type: 'audio/webm' })`. Adds file to `dataTransfer.items.add(file)` and text summary to `dataTransfer.setData('text/plain', ...)`.
    - For text: Adds text to `dataTransfer.setData('text/plain', memo.content)`.
